# Algoritimos ⚙️

## Sobre o projeto

Este repositório contém as resoluções de listas de exercícios realizadas durante aulas, utilizando a linguagem **Portugol**. O foco está em praticar algoritmos básicos para fortalecer o raciocínio lógico e a compreensão dos conceitos estudados em sala.

---

## Contexto

- Todos os códigos foram desenvolvidos como parte das atividades acadêmicas.
- A linguagem usada é **Portugol**, muito utilizada para ensino de lógica de programação.

---

## Objetivos

- Praticar a resolução de exercícios propostos em aula
- Aprimorar a lógica e os fundamentos de algoritmos
- Documentar os exercícios para revisão futura

---

## Conteúdo

- Exercícios variados que abordam:  
  - Estruturas condicionais  
  - Laços de repetição  
  - Manipulação de variáveis e operações básicas  
  - Algoritmos sequenciais e estruturados

---

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Leocm123/algoritimos.git
   
2. Abra os arquivos .alg ou .txt em um editor de Portugol (exemplo: Visualg).

3. Estude ou execute os exercícios conforme necessidade.
